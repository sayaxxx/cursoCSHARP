🎯 ¿Qué Proyecto Vamos a Construir?

Crearemos un módulo de gestión de Categorías para la tienda naturista NaturVida. Es el punto de partida perfecto porque:

  • Solo usa 1 tabla al inicio (sin relaciones complejas que distraigan).
  • Cubre el CRUD completo (Crear, Leer, Actualizar, Eliminar).
  • Permite enfocarnos 100% en Entity Framework Core + LINQ sin mezclar patrones avanzados.
  • Una vez dominado, escalaremos a Productos (2da tabla con FK) y luego al sistema completo.
💡
¿Y si mi base de datos ya existe?

En la Parte 2 te enseñaré exactamente cómo conectar EF Core a una BD ya creada (enfoque Database-First). Comenzamos con Code-First solo para que entiendas cómo EF Core "piensa", pero el 90% de los pasos son idénticos. No perderás tiempo.

1

📁 Arquitectura y Estructura de Carpetas

Mantendremos un solo proyecto WinForms (como lo hacías con ADO.NET), pero organizaremos el código en carpetas para que sea limpio y profesional:

NaturVida.App/                  ← Proyecto WinForms (.NET 10)
│
├── 📁 Models/                  ← Entidades (Clases que representan tablas)
│   └── Categoria.cs
│
├── 📁 Data/                    ← DbContext y configuración de conexión
│   └── NaturVidaContext.cs
│
├── 📁 Logic/                   ← Reglas de negocio y validaciones
│   └── CategoriaBLL.cs
│
└── 📁 UI/                      ← Formularios WinForms
    ├── frmMenu.cs
    └── frmCategorias.cs

Regla de Oro: Cada formulario solo habla con `Logic/`. `Logic/` habla con `Data/`. `Data/` habla con EF Core. `Models/` viaja entre todas las capas.

2

🔄 Enfoque: ¿Code-First o Base de Datos Existente?

🌱 Code-First (Lo que usaremos para aprender)

💡 Escribimos la clase C# primero → EF Core crea la tabla automáticamente en SQL Server.

Ventaja pedagógica: Ves cómo EF Core traduce tus clases a SQL, entiendes `Migrations`, y no dependes de scripts manuales.

🗄️ Database-First (Para producción real)

💡 Ya tienes la tabla en SQL Server → EF Core genera las clases C# automáticamente.

Cómo lo haremos: En la Parte 2, después de entender Code-First, te mostraré el comando Scaffold-DbContext para que conectes a tu BD existente en 2 pasos. El resto del curso (LINQ, CRUD, UI) es 100% idéntico.

🛠️ Requisitos Previos

1

Software Necesario

Visual Studio 2026 (con carga de desarrollo .NET Desktop), SQL Server (LocalDB o Express), SSMS (opcional pero recomendado).

2

Paquetes NuGet (Se instalan en el curso)

3

Mentalidad

Dejas de escribir SQL como texto. Ahora escribes consultas en C#. EF Core las traduce. Al principio se siente raro, pero en 2 horas será natural.

5

📐 Filosofía de Enseñanza (Cómo lo haremos diferente)

  • Cero saltos conceptuales: Cada término nuevo se compara con su equivalente en ADO.NET.
  • 1 tabla primero: Dominamos el flujo básico antes de agregar relaciones.
  • LINQ explicado con SQL al lado: Verás exactamente qué genera EF Core detrás de escenas.
  • Carpetas, no proyectos: Mantendremos tu arquitectura conocida, solo cambiamos el motor de datos.
  • Código limpio, explicaciones fuera: El código solo tiene lo necesario. Los "porqués" van en el texto.
🎯
Meta Final

Al terminar, podrás tomar cualquier tabla de tu empresa, conectarla con EF Core, y tener un CRUD funcional en menos de 1 hora, sin escribir un solo `SqlCommand` ni `SqlDataReader`.
