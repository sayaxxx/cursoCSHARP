🔄 ¿Por qué Paneles y no Múltiples Ventanas?

Tradicionalmente se usaba form.Show() o MDI, lo que generaba desorden, múltiples barras de tareas y pérdida de contexto. El patrón moderno en WinForms es el Contenedor Dinámico (Shell).

📦 La Analogía del Marco de Fotos

💡 Imagina un marco de fotos fijo en la pared (tu Panel Derecho). Cada vez que haces clic en un botón del menú lateral, quitas la foto actual y colocas una nueva. El marco nunca se mueve, solo cambia su contenido. Esto mantiene la app limpia, rápida y profesional.

💻 Paso 2: Código de Navegación Dinámica

Este es el método mágico que inyecta formularios dentro del panel sin abrir ventanas nuevas.

UI/frmMenu.csC# 14
namespace NaturVida.App.UI;

public partial class frmMenu : Form
{
    public frmMenu()
    {
        InitializeComponent();
        btnCategorias.Click += (s, e) => AbrirFormulario(new frmCategorias());
        btnProductos.Click += (s, e) => AbrirFormulario(new frmProductos());
    }

    private void AbrirFormulario(Form hijo)
    {
        // 1. Limpiar contenido anterior
        panelContenido.Controls.Clear();
        
        // 2. Configurar el formulario para comportarse como control
        hijo.TopLevel = false;              // No es ventana independiente
        hijo.FormBorderStyle = FormBorderStyle.None; // Sin bordes
        hijo.Dock = DockStyle.Fill;           // Ocupa todo el panel
        
        // 3. Inyectar y mostrar
        panelContenido.Controls.Add(hijo);
        hijo.Show();
    }
}
💡
¿Por qué TopLevel = false?

Por defecto, los formularios son "ventanas de nivel superior" (aparecen en la barra de tareas). Al ponerlo en false, le decimos a WinForms: "Trátalo como un control más, como un Button o Panel". Esto permite incrustarlo dentro de otro contenedor.

⚙️ Paso 3: Configurar Program.cs como Punto de Entrada

Asegúrate de que tu aplicación inicie en el menú, no en un formulario suelto.

Program.csC# 14
using NaturVida.App.UI;

namespace NaturVida.App;

static class Program
{
    [STAThread]
    static void Main()
    {
        ApplicationConfiguration.Initialize();
        Application.Run(new frmMenu());
    }
}

¿Cómo escalar esto al sistema NaturVida completo?
  • Agrega Cliente.cs y Vendedor.cs en Models/
  • Crea sus DAL/BLL siguiendo exactamente el mismo patrón
  • Para Facturación, usa una entidad Venta con ICollection<DetalleVenta> y transacciones: using var tx = db.Database.BeginTransaction();
  • Para reportes de inventario mensual, usa LINQ con .Where(v => v.Fecha.Month == DateTime.Now.Month)
