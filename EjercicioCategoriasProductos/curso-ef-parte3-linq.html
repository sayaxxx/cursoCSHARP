🔄 ¿Qué es LINQ? (Tu nuevo "SQL" en C#)

LINQ (Language Integrated Query) es la forma en que C# te permite hacer consultas directamente en el código, sin escribir cadenas de texto como "SELECT * FROM...".

SQL (Lo que sabes)LINQ en C# (Lo que harás)¿Qué cambia?
SELECT * FROM Categoriascontext.Categorias.ToList()En lugar de texto, usas objetos reales con autocompletado.
WHERE Activo = 1.Where(c => c.Activo)El compilador verifica errores antes de ejecutar.
ORDER BY Nombre ASC.OrderBy(c => c.Nombre)Seguro contra inyección SQL (no hay cadenas concatenadas).
SELECT TOP 1 ....FirstOrDefault(c => c.Id == 5)Devuelve null si no encuentra, nunca rompe la app.

🧩 Entendiendo la sintaxis => (Lambda)

💡 Verás mucho esto: c => c.Activo. Léelo como: "Para cada elemento c, donde c.Activo sea verdadero". La c es solo una variable temporal que representa cada fila de la tabla. Puedes ponerle cualquier nombre: x => x.Activo funciona igual.

📦 Paso 1: Practicar con Listas en Memoria (Sin BD aún)

Antes de tocar la base de datos, vamos a ver cómo funciona LINQ con una lista normal. La sintaxis es idéntica en EF Core.

Ejemplo conceptual (puedes probarlo en un archivo .cs temporal)C# 14
var categorias = new List<Categoria>
{
    new Categoria { Id = 1, Nombre = "Tés", Activo = true },
    new Categoria { Id = 2, Nombre = "Cafés", Activo = false },
    new Categoria { Id = 3, Nombre = "Endulzantes", Activo = true }
};

// 1. Traer todas
var todas = categorias.ToList();

// 2. Filtrar solo las activas
var activas = categorias.Where(c => c.Activo).ToList();

// 3. Buscar una por ID de forma segura
var cafe = categorias.FirstOrDefault(c => c.Id == 2);

// 4. Ordenar alfabéticamente
var ordenadas = categorias.OrderBy(c => c.Nombre).ToList();
💡
Clave mental:

Cuando trabajes con EF Core, solo cambias categorias por context.Categorias. El resto del código es exactamente igual.

⚡ Concepto Crítico: Ejecución Diferida

Este es el error #1 de los principiantes. En ADO.NET, cuando ejecutabas cmd.ExecuteReader(), la consulta iba inmediatamente a SQL Server. Con LINQ, la consulta se pospone hasta que realmente pides los datos.

🛒 La Analogía de la Lista de Compras

💡 Escribir context.Categorias.Where(c => c.Activo) es como anotar en un papel: "quiero solo las categorías activas". Aún no fuiste al supermercado. La consulta real solo ocurre cuando llamas a .ToList(), .FirstOrDefault() o haces un foreach. Ahí es cuando EF Core genera el SQL y va a la BD.

¿Por qué es útil? Te permite construir consultas paso a paso sin ejecutar múltiples viajes a la base de datos:

// Paso 1: Empiezas la consulta (no va a la BD aún)
var consulta = context.Categorias.Where(c => c.Activo);

// Paso 2: Agregas ordenamiento (sigue sin ir a la BD)
consulta = consulta.OrderBy(c => c.Nombre);

// Paso 3: Aquí SÍ va a la BD y trae los datos
var resultado = consulta.ToList();

💻 Cómo se ve en tu proyecto (Contexto Real)

Una vez que tengas tu NaturVidaContext configurado, así es como usarás LINQ en tu capa de lógica o UI:

Ejemplo real con DbContextC# 14
using NaturVida.App.Data;

// 1. Listar todo para un DataGridView
using var db = new NaturVidaContext();
var lista = db.Categorias.OrderBy(c => c.Nombre).ToList();
dgvCategorias.DataSource = lista;

// 2. Buscar por ID para editar
var categoria = db.Categorias.FirstOrDefault(c => c.Id == 5);

// 3. Verificar si ya existe un nombre
bool existe = db.Categorias.Any(c => c.Nombre == "Tés");
⚠️
Siempre usa using con el Contexto:

using var db = new NaturVidaContext(); asegura que la conexión se cierre automáticamente aunque ocurra un error. Es igual a cerrar un SqlConnection manualmente, pero automático y seguro.

✅ Checklist de Verificación

📝 Antes de continuar al CRUD real
  • ☑ Entendí que LINQ reemplaza las cadenas SQL por métodos C# tipados.
  • ☑ Sé leer c => c.Condicion como "donde c.Condicion sea verdadera".
  • ☑ Conozco los 5 métodos esenciales: ToList, Where, FirstOrDefault, OrderBy, Any.
  • ☑ Comprendí la "Ejecución Diferida": la BD no se consulta hasta llamar a ToList() o similar.
  • ☑ Sé que debo envolver el contexto en using para cerrar conexiones automáticamente.
