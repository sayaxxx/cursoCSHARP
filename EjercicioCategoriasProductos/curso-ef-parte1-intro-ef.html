🛠️ Paso 1: Instalación de Herramientas (NuGet)

Antes de escribir código, necesitamos instalar las librerías de EF Core. En tu proyecto de Visual Studio:

1

Abrir NuGet

Clic derecho en el proyecto NaturVida.App → Manage NuGet Packages.

2

Instalar Motor de SQL Server

Ve a la pestaña Browse y busca: Microsoft.EntityFrameworkCore.SqlServer. Instala la versión más reciente (v8 o v9).

3

Instalar Herramientas de Consola

Busca también: Microsoft.EntityFrameworkCore.Tools. Esto es necesario para crear las bases de datos desde la consola.

2

🧩 Paso 2: ¿Qué es el DbContext?

Antes de crear archivos, entendamos qué vamos a hacer. En ADO.NET, tú creabas manualmente:

  • SqlConnection: Para abrir la puerta a la base de datos.
  • SqlCommand: Para enviar instrucciones SQL escritas a mano.
  • SqlDataAdapter/Reader: Para leer los resultados y convertirlos a objetos o DataTables.

🧠 EF Core une todo en un solo objeto: El DbContext

💡 El DbContext es como el "Gerente de Sucursal". Tú no necesitas hablar con el banco (SqlConnection), ni llenar formularios (SqlCommand), ni contar el dinero manualmente (DataReader). Tú solo le dices al Gerente: "Dame la lista de categorías" y él hace todo el trabajo sucio internamente.

📁 Paso 3: Creando la Estructura de Carpetas

En tu proyecto, crea estas carpetas vacías (Clic derecho en el proyecto → Add → New Folder):

  • Models/ → Aquí vivirán tus clases (Entidades) que representan las tablas.
  • Data/ → Aquí vivirá el Contexto (la conexión inteligente).

📝 Paso 4: La Entidad (Tabla)

Crea una clase llamada Categoria.cs dentro de la carpeta Models/.

Models/Categoria.csC# 14
// Esta clase representará una fila en la tabla 'Categorias'
namespace NaturVida.App.Models;

public class Categoria
{
    // EF Core reconoce automáticamente propiedades llamadas 'Id'
    // como la llave primaria (Primary Key) de la tabla.
    public int Id { get; set; }

    // Esta propiedad se convertirá en una columna NVARCHAR
    public string Nombre { get; set; } = string.Empty;

    // Esta propiedad será una columna BIT (true/false)
    public bool Activo { get; set; } = true;
}
💡
Nota importante:

Observa que no hay código de base de datos aquí. Es una clase C# pura y simple. EF Core es lo suficientemente inteligente para mirar esta clase y deducir: "Ah, necesito una tabla con una columna Id numérica y una columna Nombre de texto".

🧠 Paso 5: El Contexto (La Conexión)

Crea una clase llamada NaturVidaContext.cs dentro de la carpeta Data/.

Data/NaturVidaContext.csC# 14
// Necesitamos esta librería para usar DbContext
using Microsoft.EntityFrameworkCore;
using NaturVida.App.Models;

namespace NaturVida.App.Data;

// El Contexto debe heredar de la clase base DbContext de EF Core
public class NaturVidaContext : DbContext
{
    // DbSet representa una tabla completa en la base de datos.
    // 'Categorias' será el nombre de la tabla en SQL Server.
    public DbSet<Categoria> Categorias { get; set; }

    // Aquí configuramos la conexión a la base de datos
    protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
    {
        // Indicamos que usaremos SQL Server y le damos la cadena de conexión
        // (localdb)\mssqllocaldb es la base de datos ligera que viene con Visual Studio
        optionsBuilder.UseSqlServer("Server=(localdb)\\mssqllocaldb;Database=NaturVidaDB;Trusted_Connection=true;");
    }
}
🧩
Desglose de conceptos nuevos:

1. DbSet<Categoria>: Piensa en esto como una "Colección de todas las Categorias". En ADO.NET, para leer datos usabas un SqlDataReader. En EF Core, lees el DbSet.

2. OnConfiguring: Este método se ejecuta automáticamente la primera vez que usas el contexto. Es aquí donde EF Core "aprende" a dónde conectarse.

3. LocalDB: No necesitas instalar un servidor SQL completo. (localdb)\mssqllocaldb funciona inmediatamente. Cuando despliegues la app real, solo cambiarás esta cadena de texto por la de tu servidor.

🆚 Comparativa: ADO.NET vs EF Core

Para que tu mente haga el cambio de "chip", veamos las equivalencias directas:

En ADO.NET (Lo que sabes)En Entity Framework Core (Lo que harás)
SqlConnectionNaturVidaContext (El DbContext)
SqlCommand ("SELECT * FROM...")context.Categorias.ToList()
SqlParameterObjetos C# (EF Core evita la inyección SQL)
SqlDataAdapter.Fill(DataTable)EF Core rellena listas de objetos automáticamente
Crear tablas manualmente en SSMSEF Core crea las tablas por ti (Migrations)
